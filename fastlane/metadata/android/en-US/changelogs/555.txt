Fix media artwork leaking across unrelated history items from the same app. Media artwork and controls are now keyed to the exact notification post (package + exact notification ID + post time), with no package-level artwork fallback. WhatsApp/other call notifications are excluded from media playback, and “Call back” is no longer misclassified as a Previous-media action. Text messages, calls, app launches and ordinary notifications therefore cannot inherit the last media/caller image from the same package. Media capture, notification visual capture, disk decoding and MediaSession lookups remain suppressed during active Vertical List scrolling so 3.30.126's smooth-scroll work is preserved. Exact notification/message destination persistence is unchanged.
