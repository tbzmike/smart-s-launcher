Remove a scroll-synchronous timer that remained in the 3.30.127 Vertical List path. ScrollIdleGate previously posted a 180 ms settle Runnable to the main UI looper and, during a continuing fling, woke and rescheduled it repeatedly until motion stopped. 3.30.129 removes that polling loop completely and uses Android ListView's native TOUCH_SCROLL / FLING / IDLE state callbacks instead. Scroll start/idle work now runs only at actual state transitions, with no periodic timer firing during the fling. This build is based directly on 3.30.127: its exact per-event media artwork, WhatsApp call/media/message separation, notification destination storage, normal icon loading and other 3.30.127 behavior are retained. None of the 3.30.128 icon-worker throttling is included.
