Vertical List now uses a hard scroll freeze instead of deferred work. History searches, history seed/preview workers, icon decoding/idle callbacks, frozen-app reconciliation, metadata refreshes, dataset publications, list animations, moving text previews, marquee/auto-expand geometry, notification RemoteViews/enrichment and optional row styling are prevented from running in the scroll hot path. Work interrupted by scrolling is dropped rather than replayed when scrolling stops. Search now publishes memory-resident app/shortcut matches immediately, uses a dedicated query worker so History cannot block typing, streams results after each provider, and disables search-result move animations.
